# Typography Rule

All pages, components, and typography across the Sanivex application must use **Poppins** as the primary font, or in its defect **Montserrat** as the secondary/fallback font.

## Standards:
- Primary font: **Poppins** (weights: 300, 400, 500, 600, 700, 800, 900)
- Fallback font: **Montserrat**
- CSS font stack: `var(--font-poppins), var(--font-montserrat), sans-serif`
- Never revert or replace these with browser defaults or other system font families without explicit user instructions.
